# MOHOMMAD FAHIM — Personal Portfolio

A self-contained, mobile-responsive, static portfolio site ready for **GitHub Pages**. No install, build tools, external libraries, or API keys are required.

## Files

- `index.html` — portfolio content and page layout.
- `styles.css` — premium dark styling and responsive layout.
- `script.js` — mobile navigation and subtle scroll effects.
- `assets/fahim-portrait.webp` — edited professional portrait.
- `assets/MOHOMMAD_FAHIM_CV.pdf` — CV file for the download button.
- `assets/favicon.svg` — site icon.

## Publish on GitHub Pages (personal repository)

1. Log in to GitHub as **fahim-2003**.
2. Create a **public** repository named exactly `fahim-2003.github.io` under your **personal** account (do not use the AeroGuardTIC organization).
3. Upload the **contents** of this folder to the repository root. Keep `assets` as a folder; `index.html` must be at the root.
4. Open **Settings → Pages**, select **Deploy from a branch**, `main` branch, `/(root)`, then **Save**.
5. After GitHub Pages deploys, open `https://fahim-2003.github.io/`.

## Customization

Edit text in `index.html`. Update project URLs if repository names change. Replace portrait/CV files in `assets/` using the same names. The site deliberately does not show your home address, birth date or phone number.

## Notes

- Projects are described conservatively. Only the AeroGuard hardware activities discussed with the owner are attributed as personal experience.
- The portrait is a stylized/edited user photo rather than an unaltered photo.
- All links and assets are relative or HTTPS, so the site can also be tested by opening `index.html` locally.
